# Odd preimages of powers of two under the Collatz map

**Not a proof of the Collatz conjecture.**

Author: Igor Tsirulnikov  
Version: 0.1  
DOI: https://doi.org/10.5281/zenodo.22749800  
License: [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/)

This note proves that an odd integer `n` satisfies `3n+1 = 2^m`
if and only if `n = (4^k-1)/3`. See `paper/paper.pdf`.
